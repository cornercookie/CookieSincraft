## Description

產品規劃層面的功能增強，不阻塞核心功能可用性與安全性：

| # | 建議 | 理由 |
|---|------|------|
| 1 | **支援保持長寬比放大** | 目前強制拉伸至目標解析度 |
| 2 | **支援自訂輸出資料夾/檔名樣板** | 目前固定 `_upscaled` 後綴 |
| 3 | **加入最近開啟檔案歷史** | 提升重複使用體驗 |
| 4 | **支援批次處理** | 單張處理效率低 |
| 5 | **加入設定檔持久化** | 記住上次使用的 backend/algorithm/quality |
| 6 | **支援 HDR 輸出** | 目前 `image` crate 僅支援讀取 |
| 7 | **WebP 有損編碼選項** | 目前僅無損 |

## Acceptance Criteria

- [ ] 保持長寬比：放大選項新增「保持長寬比」核取方塊，勾選時以短邊為準縮放
- [ ] 自訂輸出：設定頁面可編輯輸出資料夾、檔名樣板（如 `{name}_upscaled_{scale}x.{ext}`）
- [ ] 最近開啟：啟動畫面顯示最近 5 個檔案，點擊直接載入
- [ ] 批次處理：支援選取多檔/資料夾，依序放大並顯示總進度
- [ ] 設定持久化：關閉程式後重開，backend/algorithm/quality/輸出資料夾保持上次設定
- [ ] HDR 輸出：支援輸出 HDR 格式（需 `image` crate 支援或外部工具）
- [ ] WebP 有損：品質滑桿對 WebP 生效（需確認 `image` crate 版本支援）
